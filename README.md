# おみくじ・今日の運勢（mikuji）

1日1回引けるおみくじの静的Webサイトです。ビルド不要で、そのまま静的ホスティングに置けば動きます。

## 概要

- 運勢は「日付（＋任意で入力した名前）」をシードにした決定的乱数で決まります。その日は何度開いても、誰が開いても（同じ名前なら）同じ結果になります。日付が変われば結果も変わります。
- 名前・履歴などのデータは外部に送信されません。履歴と連続日数は localStorage（この端末の中）にだけ保存されます。

## 機能

- 運勢7段階：大吉・中吉・小吉・吉・末吉・凶・大凶（重み付き抽選）
- 結果の内容
  - 今日の一言
  - ラッキーアイテム（20種から）
  - ラッキーカラー（色ドット付き、12種から）
  - ミニ運勢3項目：願い事／学業・仕事／恋愛（各6パターンから）
- 引くときの演出：おみくじ箱が振れるアニメーション（約1.2秒）のあとに棒が出て結果表示
- 連続訪問日数（ストリーク）を localStorage で記録し、2日以上で「○日連続で訪問中！」と表示
- 引いた履歴（日付と運勢）を最大30日分表示
- 結果カードを Canvas（1200×630）で描画し、PNGとしてダウンロード可能
- X共有リンク（intent）で結果テキストを投稿可能
- PWA対応（ホーム画面に追加可能、オフラインキャッシュ）
- ダークモード対応（prefers-color-scheme）

## 使い方

1. 任意で名前を入力します（空欄でも引けます）。
2. 「おみくじを引く」を押すと、箱が振れる演出のあとに今日の運勢が表示されます。
3. 今日すでに引いている場合は、開いた時点で結果が表示されます。
4. 結果カードの画像保存や、Xでの共有ができます。

## 技術メモ

- 素のHTML/CSS/JavaScriptのみ。外部リソース・ライブラリ・Webフォント不使用（日本語フォントはシステムフォントスタック）。
- 決定的乱数：FNV-1aハッシュ＋mulberry32。シードは `mikuji|日付|名前`。
- ストリーク判定：最終訪問日が昨日なら+1、今日なら維持、それ以外は1にリセット。
- Service Worker（`sw.js`）：同一オリジンのGETをキャッシュ（キャッシュ名 `mikuji-v1`、stale-while-revalidate方式）。
- アイコンは Python PIL で生成（角丸の赤背景＋白文字「運」、192px / 512px）。
